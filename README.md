# Inventario Móvil TI

## Autor
Sebastián González Tapia

## Descripción
Aplicación móvil para gestionar el inventario de productos tecnológicos.

## Funcionalidades
- Registro de productos.
- Validación de datos.
- Control de entradas y salidas de stock.
- Alertas de stock bajo.
- Almacenamiento local.
- Resumen del inventario.
- Acceso a la cámara.
- Notificaciones.

## Tecnologías
- Kotlin
- Android Studio
- Jetpack Compose
- MVVM

## Ejecución
Abrir el proyecto en Android Studio y ejecutar la aplicación en un emulador o dispositivo Android.
